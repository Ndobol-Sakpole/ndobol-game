# UI styles
`style.css` mendefinisikan token warna, tipografi sistem (Georgia/Arial), lobi, HUD, panel debug, dan kontrol sentuh. Breakpoint 900px. Aset gambar/font eksternal tidak diperlukan. State dari UI: `hidden`, `aria-pressed`, `aria-expanded`, dan `body.playing`.

play.css menambahkan tema game hijau gelap/emas, garasi getek, telemetry keseimbangan/arah, dan kontrol sentuh 390px. Diletakkan setelah style.css; tidak memengaruhi website promosi frontend/.

river.css supplies Start flow, real logo, optional wallet dialog, free gas controls and responsive overrides.
