# ABI contracts
`INdobolItems.mint(to,id,amount,data)`; `IRiverRegistry.submitRound(RoundResult,signature)` dan `isRecorded(roundId)`; `IImpactBadge.award(player,badgeId,roundId)` dan `hasBadge(player,badgeId)`. RoundResult fields dan event terdokumentasi di Solidity. bytes32 IDs memerlukan canonical encoding yang disepakati pada Fase 2; frontend belum mengirim transaksi.
